# Trabalho Fnal de Criptografia

## 1 Objetivo
O objetivo deste projeto é projetar e implementar um protótipo de uma aplicação de chat segura. Os alunos deverão aplicar conceitos fundamentais de criptografia simétrica e assimétrica para construir um canal de comunicação onde a confidencialidade das mensagens seja garantida. 
O projeto envolve a criação de uma arquitetura cliente-servidor simples que negocia chaves de forma segura e, em seguida, cifra as mensagens da sessão usando modos de operação de cifra de bloco específicos.
